# 객체 소실·급변 대조 평가셋과 기준선 (2026-11-18)

LaSOT 원본 3개와 자체 통제 합성 영상 18개로 대조 개발셋을 만들고, 기존 **0.13.0 검출기와 기본 설정을
변경하지 않은** 실제 Video Intelligence → 객체 후보 → 원본 근거/리포트 경로를 측정했다.
합성 사건 8건 중 시공간 후보 재현율은 **4/8(50%)**, 기대 유형 코드 포함은 **3/8(37.5%)**다.
이는 통제된 소규모 개발셋의 후보 검출 결과이며 실제 AI 생성 결함 성능·품질 게이트 합격이 아니다.

## 평가셋과 고정 조건

| 계층 | 구성 | 용도 |
|---|---|---|
| LaSOT 원본 | book-3, bottle-12, bottle-1: 10초씩 3개 | 실제 움직임/가림/퇴장 구간의 검토 후보 부담. AI 결함 정답 없음 |
| 통제 정상 | 책/병 2개 대상 × 정적 유지·가림·퇴장·컷·전역 이동: 6초씩 10개 | 정상 변화 대조, 후보 부담과 판단 불가 함께 확인 |
| 통제 결함 | 같은 대상 × 소실·위치·면적·종횡비 급변: 6초씩 8개 | 정확히 3초에서 통제한 사건의 후보 재현율 |

합성 대상은 LaSOT 책/병 사진의 사각형 크롭이며 합성 배경 위 정적 스프라이트다. 분할 마스크를 사용하지
않아 주변 배경·손 일부도 포함된다. 원본 영상 안에서 실제 객체만 편집한 자료나 AI 모델이 생성한 결함이
아니다. 크롭 축소 후 책 170×62, 병 69×130 픽셀을 640×360 영상에 배치한다. 생성 라벨과 인코딩 프레임을
확인했다. 같은 원본의 정상/이상 변형은 같은 development 계보로 묶고 독립 표본이나 holdout으로 세지 않는다.

소실은 3초 이후 스프라이트 제거, 위치는 중심 x를 240→465로 이동, 크기는 양 축 1.4배, 종횡비는
폭 1.6배·높이 1/1.6배(정수 반올림)다. 정상 퇴장/가림은 연속 이동이며 컷은 배경도 동시에 바뀐다.
전역 이동은 화면 전체 수평 이동이며 경계는 순환 처리한다. 실제 카메라의 회전/원근/복잡한 배경은 포함하지 않는다.

30 FPS는 지정값이다. 원본 구간과 사진 번호·해시·크롭·계보, 합성 프레임별 시각/ROI/가시 여부를 기록했다.
검출기는 전체 API 트랙을 검사하며 GT 연결로 특정 트랙만 고르지 않는다. API에는 영상 바이트만 전달한다.

## 채점 계약

- 실행 전 `plan.json`/SHA256, 기본 설정, 검출기 소스 해시와 요청 상한을 고정했다. 검출 임계값 튜닝 없음.
- 표시된 후보의 시간 구간이 사건 [3, 3+1/30)에 ±0.25초 허용으로 겹치고, 후보 ROI가 변화 전/후 대상
  박스 중 하나와 IoU ≥ 0.2이면 사건 후보 검출이다. 영상별 사건 1개, 일대일 대응이며 중복 후보는 TP로 더하지 않는다.
- 후보 재현율과 **기대 코드 포함 재현율**을 구분한다. 시공간으로 맞아도 코드가 다르면 후자는 실패다.
  병 위치 급변이 종료 후보로 나온 것이 이 경우다. 모든 출력은 candidate/uncertain이며 결함 확정이 아니다.
- 실패·미실행·관찰 불가 양성도 전체 8건 분모에 남긴다. 무결성 불일치는 정상/누락 채점 대신 평가를 중단한다.
- 정상 합성의 후보/영상, 원본 LaSOT의 검토 후보 수, 해당 객체 검사 coverage와 실행 상태를 따로 집계한다.
  다른 5개 검사 미실행 때문에 생기는 전체 review_status를 객체 검사의 실패율로 쓰지 않는다.
- 사건 전 공간 관측 진단: [2.5, 3) 가시 GT 프레임과 ±0.06초·IoU ≥ 0.2·API confidence ≥ 0.5로 겹치는
  관측의 비율이다. 3초 이후 관측은 사용하지 않는다. 평가 전용 위치 지표이며 동일 객체 재식별/정확도 지표가 아니다.

## 원인 확인과 다음 보완

1. **변화 전 객체 관측 부족**: 책 소실/위치는 API 트랙 자체가 없었다. 크기/종횡비 변화는 3초 이후에만
   트랙이 시작됐다. 따라서 네 양성 모두 사건 전 대상 관측률 0이며 규칙이 비교할 쌍이 없었다.
   후처리 임계값을 낮추는 것만으로 해결되지 않는다. 같은 사례에서 대상 탐색/추적 보강 및 최소 관측 구간을 비교해야 한다.
2. **위치 급변과 소실의 혼동**: 병 위치 이동에서 전/후 트랙이 분리되고 서로 다른 entity 설명이 반환돼
   `OBJECT_TRACK_END` 후보가 출력됐다. 위치는 맞지만 위치 변화 코드 재현율은 0/2다. 외형/근접 구간의
   후속 트랙 대응을 검토하되 실제 소실·정상 퇴장의 오탐 회귀도 함께 확인해야 한다.
3. **coverage 해석 한계**: 책 크기/비율은 이후 트랙이 있어 검사 completed지만 사건 전은 미관측이다.
   현재 clip 단위 완료 상태는 모든 대상·시점 검사 완료를 보장하지 않는다. 시간/대상별 관측 공백 표현이 후속 대상이다.
4. **자료 확장**: 고정 사진/2개 계보/단순 배경이라 domain 차이가 크고 공급 API의 대상 설명도 실제 책/병과
   어긋나는 경우가 있다. 원본 장면 안의 통제 편집·다른 크기/가시성·실제 자체 결함 자료로 확대해야 한다.
   현재 결과를 보고 잘 검출되는 대상만 남기거나 동일 계보를 holdout으로 옮기지 않는다.

## 실행·재현·검증

- 실제 신규 요청 **18회**, 합성 영상 총 **108초**. 기존 LaSOT 3회 응답은 동일 영상 해시를 확인해 재사용했다.
  `builtin/stable`, `dev-comfyui`, `asia-east1`; 요청당 SDK/operation/해시/시간은 로컬 request.json에 있다.
  관리형 `builtin/stable`의 내부 가중치는 고정할 수 없으므로 동일 응답 재생과 미래 신규 호출을 구분한다.
  자동 제출 재시도는 0회이며 비용은 미확인(`actual_cost_usd=null`)이다.
- 신규 API 세션 시간 합계 약 333.23초(두 요청 동시 실행이므로 wall-clock 합계와 다름).
  로컬 검수 시간 p50 약 0.32초, p95 약 6.51초. 6초 합성과 10초 원본을 섞은 작은 실행의 진단치로 SLA가 아니다.
- 원시 영상·응답·전후 증거·HTML·manifest는 `work/object-comparison-2026-11-18/`에 보존했다(약 100 MiB).
  `review.html`에서 정상 대조·결함 영상과 개별 근거 리포트를 확인할 수 있다. 21개 리포트 artifact 검증 통과.
  생성 당시 코드의 원본은 같은 경로 `generator_snapshot.py`, 채점 코드 해시는 최종 summary.json에 있다.
- 전체 회귀 **222개 통과** 후 평가 진단 경계/정상 대조 시험을 추가하고 관련 객체 시험 **22개 통과**.
  테스트의 API 응답은 모의 자료이며 위 실측 18회에는 실제 공급 API 응답을 사용했다. 최종 검증 기록은
  같은 보고서 하위 디렉터리에 보존한다. 새 의존성·타 서비스 코드/자료 사용 없음.

③ 객체 검사는 **3단계 진행 중(2단계 완료)**으로 갱신한다. 이번 범위인 대조셋/기준선은 완료했고,
검출기 보완→같은 조건 재평가, 실제 결함 범위 확대, 독립 품질/운영 검증은 남아 있다.
