# SPOTLIGHT 모델별 10개 POC 비교 — 2026-11-04

사용자 요청에 따라 Seedance, Veo3, LTX-2를 각각 10개씩, 총 30개 영상으로 비교한다.
검사 경로는 1·2순위 영상 POC의 `combined`이며, 원본 SPOTLIGHT 라벨은 추론이 끝난 후 비교에만 사용한다.
검수 모델은 Vertex AI `gemini-4-argon` 우선, 사용 불가 시 `gemini-3.8-flash`다.

## 표본과 재사용

[고정 선정 파일](spotlight_poc30_selection_v1.json)에 30개 ID, 데이터/분할/설정 해시,
재사용 리포트 경로·해시, 신규 실행 18개 ID와 선정 규칙을 보관한다.

- 개발 세트 60개에서만 선정했다. holdout 540개는 검사·튜닝하지 않는다.
- 같은 프롬프트 그룹 10개를 세 생성 모델 모두에 사용한다. 프롬프트 출처 5종에서 각각 2개 그룹이다.
- 그룹은 `sid_013`, `sid_024`, `sid_040`, `sid_041`, `sid_082`, `sid_090`, `sid_119`,
  `sid_128`, `sid_172`, `sid_178`이다.
- 기존 파일럿 4개 그룹을 유지하고, 나머지 6개는 seed
  `anomaly-v4-spotlight30-20261104-v1`과 그룹 ID의 SHA-256 순서로 선택했다.
  새 표본 선정에 오류 설명·난이도·검출 결과를 사용하지 않았다.
- 기존 12개는 구현 소스 해시, 매체 해시, 규칙 및 모델 설정이 일치하는 성공한 combined 결과를
  재사용했다. 신규 18개만 추가 호출했다. 비교 생성 시 30개 원본 영상 해시를 다시 확인한다.
- 기존 파일럿에는 라벨을 고려해 선택했던 영상이 포함된다. 대표 표본이나 독립 최종 평가 세트가 아니다.

## 비교표의 의미

SPOTLIGHT의 `difficulty`는 **개별 원본 오류**의 easy/medium/hard다. 영상 전체의 등급이 아니며,
우리 모델의 obvious/minor/deferred 또는 사람의 최초 1배속 관측과 자동 대응시키지 않는다.
선정한 30개에는 원본 오류 85개(easy 34, medium 26, hard 25)가 있으며 원본 구간 오류는 없다.

HTML과 CSV는 원본 유형·난이도·구간·설명과 서비스 후보의 유형·출처·구간·설명·가시성을 나란히 제공한다.
원본 라벨 6종을 모두 보여주되 POC 범위와의 관계를 표시한다. 등장·소실은 1순위와 관련되고,
motion/logical은 시간적 불안정과 일부 겹친다. 물리·인체·프롬프트 전체 검사는 아직 지원하지 않는다.
이는 설명을 위한 범위 안내이며 유형별 정답 매핑 규칙이 아니다.

시간 구간 IoU ≥0.1인 후보를 원본 오류 옆에 연결한다. **시간 겹침은 검출 성공 판정이 아니다.**
이 보조 비교에서는 유형을 제한하지 않고 대상·내용이 같은지 판정하지 않는다. 한 후보가 여러 라벨과,
한 라벨이 여러 후보와 겹칠 수 있다. 따라서 겹친 라벨 수를 TP·재현율·정밀도라고 해석하지 않는다.
정확도·재현율 필드는 null이고 사건 일치 상태도 미검수로 남긴다. 공식 SPOTLIGHT 평가 지표를 구현한
결과도 아니다. 실제 검출 성공은 구간과 현상 설명을 함께 확인해야 한다.

부분 실행, 원본 구간 오류, 후보 시간 미상은 비교 보류/제외로 구분한다. 유효한 후보 없음이나 원본
주석 없음도 정상 인증이 아니다. 원본 라벨을 우리 후보로 덮어쓰거나, 기존 사람 정답을 수정하지 않는다.

## 출력과 재현

결과 폴더: `work/spotlight_poc30_comparison_20261104/`

| 파일 | 용도 |
|---|---|
| `index.html` | 생성 모델별 요약, 모델·난이도·파일명 필터, 30개 비교표, 영상 재생과 오류별 상세 |
| `videos.csv` | 영상별 원본 난이도 수와 유형/설명, POC 후보 수·유형/설명 |
| `annotations.csv` | 원본 오류별 난이도·구간·설명·검사 범위·시간이 겹치는 후보 ID |
| `candidates.csv` | 실제 표시된 POC 후보별 유형·구간·출처·설명·가시성·정상 대안 |
| `comparison.json` | 원본 라벨·후보·해시·실제 모델·실행 상태·비교 정책을 담은 전체 기록 |

CSV는 UTF-8 BOM이며 스프레드시트 수식으로 해석될 수 있는 문자열은 안전하게 인용한다.
JSON의 원문은 유지한다. HTML의 외부 텍스트는 escape 처리한다. 영상/근거는 기존 실행 폴더에
상대 링크하므로 HTML 파일 하나만 복사하면 재생·리포트 링크가 끊긴다.

비교 생성은 모델을 호출하지 않는다. v4 디렉터리에서 다음 명령을 사용한다.

```bash
.venv/bin/python -m review_anomaly_v4.spotlight_comparison \
  --dataset-root benchmarks/datasets/spotlight \
  --selection benchmarks/spotlight_poc30_selection_v1.json \
  --manifest benchmarks/spotlight_split_manifest_v1.json \
  --runs work/spotlight_poc30_new_20261104/runs.json \
  --output work/spotlight-poc30-comparison-new
```

출력은 새 폴더여야 한다. `--runs`에 후속 재실행 목록을 추가할 수 있으며 성공 결과를 우선한다.
30개 전체를 새로 검사한 목록을 넣으면 신규 성공 결과를 사용하므로 기존 파일럿 리포트가 없어도 된다.
동일한 그룹 구성·분할·매체 해시·검사 범위·규칙·모델 설정을 검증한 뒤 표를 만든다.

검증: 기존 테스트 포함 95개 통과, Ruff 통과. 추가 검증은 원본 난이도 보존, 비정답 시간 겹침,
부분 실행·잘못된 구간·시간 미상 구분, holdout/매체 해시/규칙 혼합 거부, HTML·CSV 출력 보호를 포함한다.
원본 동영상·라벨 상세·추론 응답이 들어 있는 `work/`는 Git 제외 대상이다.
