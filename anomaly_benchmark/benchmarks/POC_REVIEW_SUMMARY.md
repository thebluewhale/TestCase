## 원본 상태와 평가 기준

- 원본 주석이 있는 29개 영상은 ‘오류 라벨 있음’이다. 이것은 SPOTLIGHT 주석 기준이며 독립된 재검증이 아니다.
- 원본 주석이 없는 `sid_082_ltx2`는 ‘주석 없음·정상 미확정’이다. 정상 샘플로 간주하지 않는다.
- easy/medium/hard는 개별 원본 오류의 난이도다. 영상 단일 등급이나 수정 우선순위로 바꾸지 않는다.
- `poc_scorecard.py`는 검출 후 원본 설명과 후보 설명만 Vertex Gemini로 대조한다. 영상을 다시 검사하지 않는다.
  검출 툴의 입력에는 정답을 추가하지 않는다. 내용 평가에는 시간·원본 유형·난이도를 주지 않는다.
- 모델은 모든 원본/후보 쌍을 `same/different/uncertain`으로 판단하고 짧은 한국어 이유를 남긴다.
  같은 대상과 중심 오류 현상을 설명해야 same이다. 같은 장면·물체·오류 종류라는 이유만으로 일치시키지 않는다.
- 자동 일치는 same과 시간 IoU ≥0.1을 모두 만족해야 한다. 일대일 최대 매칭으로 수를 정하고,
  같은 대응 수일 때 총 IoU가 높은 조합을 선택한다. 하나의 후보를 여러 정답에 중복 가산하지 않는다.
- 객체를 식별하지 못한 측정 가설은 텍스트만으로 같은 사건임을 확인할 수 없어 same 판정을 보류로 낮춘다.
  모델 원판정과 이 규칙의 적용 여부를 모두 기록한다. 이는 실제 영상에서 해당 후보가 무용하다는 뜻이 아니다.
- 미일치는 내용 불일치 또는 구간 기준 미충족이다. 불확실한 대응, 원본 구간 오류, 검사/평가 미완료는 보류다.
- 미대응 후보는 정답과 연결되지 않은 제안이다. 새로운 미주석 오류일 수도 있으므로 자동 오탐으로 확정하지 않는다.

**사람 검증 전의 자동 대조 결과다.** 검출 모델과 평가 모델은 같은 계열이고 평가자는 영상을 보지 않는다.
원본 오류의 존재 자체, 원본 주석의 정확성, 새 후보의 실제 타당성을 확인한 결과가 아니다.
공식 SPOTLIGHT 점수를 재현한 것도 아니다. 원본 인체·물리·프롬프트 오류를 포함한 전체 85개가 분모이므로,
이 숫자를 현재 1·2순위 검사 범위만의 재현율로 해석하면 안 된다. 기존 사람 전체 검수 정답과도 별개다.

## 재현과 보관

```bash
.venv/bin/python -m review_anomaly_v4.poc_scorecard \
  --comparison work/spotlight_poc30_comparison_20261104/comparison.json \
  --evaluations work/spotlight_poc30_event_judgments_20261104 \
  --output work/poc30-summary-new \
  --vertex-project YOUR_PROJECT_ID
```

평가 JSON은 요청 해시를 검증해 재사용한다. 출력 폴더는 새 경로를 사용한다. 프로젝트·인증은 Vertex 호출
규약을 따른다. 요청·원문 응답·실제 모델·usage·실패를 개별 평가 JSON에 기록하고, 인증 토큰은 저장하지 않는다.
`scorecard.json`에는 원본 comparison 해시와 대응 근거를 보존한다. 한국어 요약은 모델 번역이며 원문은
기존 comparison/개별 리포트에 유지한다. 평가 JSON과 미디어는 Git 제외 `work/`에 둔다.

검증: 전체 106개 테스트 통과, 최종 표시 보완 후 관련 11개 재검증 통과. Ruff 및 v4 독립성 검사 통과.
내용 불일치, 시간 불일치, 중복 대응, 모호한 측정, 실패·주석 없음의 처리와 HTML 출력 보호를 확인했다.
