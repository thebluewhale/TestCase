# 객체 소실·급변 대조 개발셋 v1

2026-11-18에 기준선 실행 전 고정한 계획/라벨/설정 스냅샷이다. `plan.json`의 모든 미디어·라벨 경로는
**로컬 실행 디렉터리** 기준이며 이 문서 디렉터리를 미디어 루트로 사용하지 않는다.
현재 실행 루트는 v3 내부 `work/object-comparison-2026-11-18/`이다. 영상·API 응답·검수 HTML은 Git/Docker 제외다.
라벨은 평가 전용이며 추적 API와 객체 검출기에 전달하지 않는다.

- 원본 LaSOT: 기존 3개 × 10초. AI 결함 라벨이 없으므로 검토 후보 부담만 측정.
- 합성: 2개 대상 × 9개 변화 × 6초. `steady`, 가림, 퇴장, 컷, 카메라 이동은 정상 대조 10개.
  소실, 위치, 면적, 종횡비 급변은 양성 8개이며 3초에 발생한다.
- LaSOT `book-3` 원본 프레임 1, `bottle-1` 원본 프레임 2156(파생 구간의 270)을 사각형 크롭해
  결정론적 배경에 합성했다. 원래 배경·손 일부가 포함될 수 있으며 정밀 객체 분할 자료가 아니다.
- 30 FPS는 생성/변환 지정값이며 LaSOT 원본 FPS의 확인값이 아니다. 동일 원본의 모든 변형은 같은
  development 계보다. holdout/실제 AI 생성 결함 정답/사람이 승인한 정상 광고셋이 아니다.

`labels/*.json`에는 프레임별 시각·대상 사각형·완전 가시 여부가 있다. 사라진/화면 밖 대상의 박스는
이전 또는 가상 좌표를 보존하고 `fully_visible=false`로 표시한다. 가림 중 일부 노출도 false다.
`plan.json`의 `events`는 사건 발생 구간 [3, 3+1/30)과 변화 전/후 ROI, 기대 코드 및 영향 종료 6초를 구분한다.
`pair_id`는 같은 대상의 steady 대조를 가리킨다. 원본 LaSOT 샘플의 빈 events는 정상 확정 라벨이 아니다.
