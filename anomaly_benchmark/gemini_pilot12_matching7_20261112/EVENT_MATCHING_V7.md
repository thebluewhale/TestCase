# 의미 매칭 v7 — 차이의 위치와 심각도 분리

2026-11-12 구현 완료. 의미 계약 `event-claims-7`, 집계 `event-aggregation-4`.
현재는 **비교 평가 단계**이며 새로 인정된 대응을 분리하여 확인한다.
검출 모델·후보 생성·원본 라벨·시간 보조 기준·85% 목표는 변경하지 않는다.

## 변경 이유

v6는 `conflict_scope=matched_claim`을 긍정 대응에서 일괄 제외했다.
이는 차이가 있는 위치와 차이의 심각도를 혼동한다. 예를 들어 동일한 닦기 전환에서
R은 원래 유리잔의 소실을, C는 닦는 도구로의 변형을 기술할 수 있다.
R이 대체 물체의 부재까지 명시하지 않았다면 두 기술은 양립할 수 있다.
하지만 소멸과 변형을 보편적인 동의어로 간주해서는 안 된다.

## 허용 조건과 방어 기준

`event_matching.positive_supported`를 응답 검증과 집계가 공동 사용한다.

| 설명 관계 | 범위 | 긍정 대응 가능 여부 |
|---|---|---|
| compatible | none | 다른 모든 근거 조건 충족 시 가능 |
| minor_discrepancy | peripheral / other_claim | 기존 조건 유지 |
| minor_discrepancy | matched_claim | 동일 사건 근거와 양립 설명이 모두 있을 때 추가 허용 |
| core_conflict | 모든 범위 | 긍정 대응 금지; 기존 불일치 검토 규칙 적용 |
| insufficient 또는 불확실한 범위 | 모든 범위 | 긍정 대응 금지·보류 |

추가 허용에도 다음 조건은 모두 유지한다.

- 선택한 원본 R 증상은 complaint 역할이어야 하며, R/C 양쪽 원문 인용이 유효해야 한다.
- 대상은 same/same_interaction, 사건은 equivalent/same_event_different_aspect,
  연결은 same_observation/partial_event/process_result여야 한다.
- `separation_basis=none`이어야 한다. 다른 대상·다른 상호작용·별개 사건·명시적 모순을
  `minor_discrepancy`나 설명 문구만으로 덮을 수 없다.
- `conflicts_ko`에 차이를 기록하고, 새 필드 `coexistence_explanation_ko`에 동일 대상,
  구체적인 상호작용/전환, 두 진술이 함께 성립할 수 있는 이유를 설명해야 한다.
  해당 조합의 긍정 판정에서 빈 설명은 검증 실패다. 그 외 조합은 빈 문자열을 허용한다.
- 단순 생략을 명시적 부정으로 확대하지 않는다. 반대로 '대체 물체가 전혀 없다',
  '동일 동작 내내 원래 형태를 유지한다' 같은 명시적 조건을 생략으로 취급하지 않는다.
- R1 대응이 R2 대응을 자동 생성하지 않는다. 각각의 선택된 원본 지적을 독립 평가한다.
- measurement_proposal, 문맥만의 일치, 라벨 밖 관측은 성공에 포함하지 않는다.

양립 설명은 **채점 모델의 주장**이다. 코드가 설명의 실제 의미나 영상 속 사실을 증명하는 것은 아니다.
모델이 중요한 차이를 사소하다고 오판할 위험은 남으므로 반례 검증과 추가 인정 쌍의 사람이 보는 검토가 필요하다.

## 비교 집계

| 필드 | 의미 |
|---|---|
| pairs.scope_rule_extension | 같은 v7 응답에서 새 matched_claim 허용에 의존한 긍정 대응 |
| pairs.semantic_correspondence_without_scope_extension | 같은 응답에서 새 허용을 끄더라도 인정되는 대응 |
| pairs.coexistence_explanation_ko | 두 설명이 함께 성립하는 이유에 대한 모델 설명 |
| video.scope_extension_only_video_hit | 새 허용 쌍이 없으면 hit이 성립하지 않는 영상 |
| video.without_scope_extension_video_hit | 새 허용 쌍을 제외해도 hit인 영상 |
| summary.scope_extension_pairs / scope_extension_only_video_hits | 해당 쌍·영상 수 |

이 비교는 **같은 새 채점 응답에 허용 조건만 다르게 적용**한 것이다. 과거 v6 모델 응답을
재현하는 값이 아니다. 실제 이전 결과와의 증감은 별도로 기록하며 새 응답의 변동과 규칙 효과를 혼동하지 않는다.
새 규칙 의존 쌍은 `needs_human_review=true`를 유지한다. 시간 차이는 기존처럼 보조 정보다.
채점 검증 실패의 국소 격리와 미완료 불일치 검토의 보류는 집계 v3 정책을 유지한다.

## 버전·캐시·검증

- 프롬프트와 스키마가 바뀌었으므로 v6 채점 캐시를 그대로 사용하지 않는다. 요청 해시·버전 검증을 우회하지 않는다.
- R 단독 분석, 비교, 필요 시 불일치 검토와 1회 재비교를 새로 수행한다. 검출 결과는 고정한다.
- 기존 입력·후보·순서·원본 파일 해시를 검증하고 별도 평가 폴더로 출력한다.
- 로컬 테스트 **435개 통과**, Ruff 및 다른 anomaly 버전 독립성 검사 통과.
- 새 회귀 검증: 사소한 동일 지적 차이의 허용, 양립 설명 누락, 다른 대상·상호작용·사건,
  명시적 모순, 불충분한 근거, 조작 인용, 측정 제안, R 간 잘못된 대응 전파 방지,
  기존 캐시 거절, CSV/HTML 비교 집계 표시.
- 별도 합성 대조 사례는 실제 영상의 새 정답이 아니다. 기대 판정은 모델에 전달하지 않고
  모델에 R/C만 제시하여 실제 출력의 과대 인정 여부를 확인한다. 표본이 작아 일반 오탐률을 보장하지는 않는다.

## 기존 Gemini 단독 12개 재채점 결과

원본 영상과 검출 후보 47개·순서·bbox·R 원문을 고정했다. 검출 재호출은 **0회**,
새 의미 채점 77회, 별도 합성 대조 채점 17회를 수행했다. v6 캐시는 재사용하지 않았다.
동결 소스/입력 해시는 실행 전후 일치했다.

| 항목 | 이전 v6 | 현재 v7 비교 |
|---|---:|---:|
| hit | 8 | 10 |
| pending | 4 | 2 |
| no_hit | 0 | 0 |
| 채점 전체 유효 / 일부 유효 / 무효 | 9 / 1 / 2 | 10 / 2 / 0 |

- 같은 v7 응답에서 새 허용을 끄면 hit 8개, 켜면 10개다. **새 허용 의존 쌍은 11개**이며
  그 쌍에만 의존한 hit 영상은 `sid_040_seedance`, `sid_079_veo3`다.
- `sid_040_seedance`의 R1–C1/C3가 minor_discrepancy + matched_claim + 양립 설명으로 인정됐다.
  R2의 명시적 대체 물체 부재까지 자동으로 대응시키지 않았다.
- `sid_079_ltx2`도 이전 pending에서 hit으로 바뀌었으나 새 허용 의존 영상은 아니다.
  새 채점 응답이 검증을 통과한 영향과 규칙 효과를 분리한다.
- `sid_053_veo3`는 이전 hit에서 pending으로 바뀌었다. 후보는 동일하며 새 응답은
  바운스/비행과 형태 변형/재출현의 사건 연결을 인정하지 않거나 보류했다.
- 남은 pending은 `sid_013_ltx2`, `sid_053_veo3`다. 두 건 모두 채점 응답은 유효하고 의미 판단이 보류됐다.
- 직전 실제 v6 판정 대비 새로 생긴 대응은 13쌍이다. 이는 동일 응답 내 허용 규칙 의존 11쌍과 다른 집합이다.
- 10/12=83.3%로 85% 목표에 필요한 11/12에는 아직 미달한다. 개발에 사용한 표본이며 일반 정확도가 아니다.

실제 모델 대조 사례 **6/6 통과**: 생략된 결과를 달리 기술한 양립 사례 1개는 hit,
명시적 형태 유지, 다른 사람, 별개 사건, 연결 근거 부족, 대체 물체 부재를 명시한 반례 5개는 모두 no_hit이었다.
기대 판정은 모델에 보내지 않았다. 이는 이번 작은 대조 집합에서의 확인이며 과대 인정 위험이 사라졌다는 뜻은 아니다.
대조 원문과 기대 판정은 [고정 대조 사례](event_matching_v7_controls.json)에 보존했다.

리포트: `~/TestCase/anomaly_benchmark/gemini_pilot12_matching7_20261112/index.html`.
`summary.html`은 두 종류의 변화 비교, `scope_extension_pairs.csv`는 새 허용 의존 11쌍,
`new_vs_previous_pairs.csv`는 실제 직전 결과 대비 새 대응 13쌍이다.
CSV에는 전체 원본 R/C·인용·양립 설명과 빈 `review_decision`, `review_note`를 제공한다.
사람 검토 시 `review_decision`에 `match` / `no_match` / `uncertain`을 적고 판단 근거를 남길 수 있다.
이 파일은 아직 채점 입력으로 사용하지 않으며 작성만으로 자동 결과가 바뀌지 않는다.
