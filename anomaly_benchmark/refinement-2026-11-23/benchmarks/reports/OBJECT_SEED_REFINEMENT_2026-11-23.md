# 객체 첫 프레임 탐색·보조 추적 보완 (2026-11-23, 0.14.0)

사용자가 확인한 같은 21개 영상에서 **책 결함 4건의 후보 검출을 회복**했다. 기존 병 결함 4건도 유지해
사건 후보 재현율은 4/8→8/8이다. 유형 코드까지 맞은 것은 3/8→6/8이다. 정상 영상의 오탐 7건은 그대로이며,
양성 영상의 미매칭 후보 1건과 정상 영상의 판단 근거 부족 증가(4→5개)가 남아 있다. 실제 AI 결함 성능이나
독립 품질 게이트 통과를 의미하지 않는다.

## 변경 사항

- `adapters/object_seed.py`: 원본 첫 프레임 한 장에서 Gemini가 최대 6개의 보이는 객체와 위치를 탐색한다.
  API에 정답 시간·ROI·파일명 의미·정상 원본·결함 설명을 전달하지 않는다. 결함을 판정하는 요청도 아니다.
  영상/프레임/응답 해시, 모델·프롬프트·토큰·시간을 보존하며 미완료 제출 자동 재시도는 없다.
- `observations/seed_tracking.py`: 초반 0.5초에 기존 API의 충분한 관측이 없는 대상만 보강한다.
  첫 프레임 외형을 고정하고 휘도 기반 정규화 상관으로 위치를 찾는다. 가까운 위치의 강한 일치를 먼저
  확인하고, 부족하면 제한된 폭/높이 축척을 전체 화면에서 비교한다. 경쟁 위치가 비슷하면 보류한다.
  압축 색차의 축척 오차를 줄이기 위해 휘도·cubic 보간을 사용했다.
- 첫 프레임/첫 샷 범위, 축소 폭 640, 표본 간격 0.1초, 최대 1,200표본/60초·6개 초기 대상이다.
  실제 PTS를 사용한다. 가림·외형 변화로 서서히 일치가 무너지면 미해결, 컷/영상 끝은 종료 대안으로 남긴다.
  예산 절단을 객체 소실로 처리하지 않는다. 회전·정밀 분할·가림 이후 재식별·새로 등장하는 모든 객체 탐색은 없다.
- API 후보를 그대로 보존한 채 보조 후보와 관측을 추가하고, 같은 시공간·유형으로 겹치는 두 경로의
  중복만 병합한다. 원시 ID/근거는 보존한다. 보조 경로 실패가 기존 API의 유효 후보를 없애지 않는다.
- `analyze-objects --seed-dir`로 명시적으로 사용한다. 인자가 없으면 기존 경로를 사용한다. 관리형 탐색 호출은
  별도 `scripts/discover_object_seeds.py`에서 수행한다. 검수 단계에서 몰래 새 API를 호출하지 않는다.
- `tracking` 선택 의존성으로 OpenCV를 v3 자체 pyproject/uv.lock/환경에 추가했다. 다른 서비스의 코드·모델·자료를
  사용하지 않는다. OpenCV는 실행 시 선택적으로 로드되며 없는 상태에서 요청하면 보조 실패를 남긴다.

[OpenCV 템플릿 매칭 문서](https://docs.opencv.org/4.x/d4/dc6/tutorial_py_template_matching.html)를 구현 참고로
사용했다. 상관 점수는 동일 객체일 확률이나 의미상 객체 탐지 정확도가 아니다.

## 동일 조건 비교

입력 21개·영상 해시·생성 라벨·사람 검수·매칭 허용치를 유지했다. 시각 ±0.25초와 변화 전/후 ROI IoU ≥0.2,
코드 무관 후보 검출 및 기대 코드 포함 점수를 분리한다. 기존 Video Intelligence 응답은 모두 재사용했다.
같은 계보의 개발셋이며 최적화에 사용한 자료를 독립 평가셋으로 바꾸지 않는다.

| 지표 | 이전 0.13.0 | 보완 0.14.0 |
|---|---:|---:|
| 책 결함의 사건 후보 검출 | 0/4 | 4/4 |
| 병 결함의 사건 후보 검출 | 4/4 | 4/4 |
| 전체 사건 후보 검출 | 4/8 | 8/8 |
| 기대 유형 코드 포함 | 3/8 | 6/8 |
| 정상 13개 영상의 오탐 후보 | 7 | 7 |
| 합성 정상 10개 영상의 후보 | 0 | 0 |
| 양성 영상의 추가 미매칭 후보 | 0 | 1 |
| 정상 영상의 판단 근거 부족 | 4/13 | 5/13 |
| 양성 영상의 판단 근거 부족 | 2/8 | 0/8 |

책의 네 결함 모두 변화 직전 공간 관측 진단이 0→약 93.3%로 개선됐다. 이 진단은 [2.5,3) 가시 프레임과
±0.06초/IoU ≥0.2로 겹치는 관측 비율이며 전체 추적/동일 객체 정확도가 아니다. 코드별로는 소실 2/2,
위치 1/2, 크기 2/2, 비율 1/2다. 책 비율 변화와 병 위치 변화는 아직 종료/소실 후보로 나온다.

추가 미매칭 후보는 병 위치 영상의 초기 탐색 박스가 배경을 많이 포함한 보조 추적에서 나왔다.
기존 후보와 영역이 충분히 겹치지 않으므로 억지로 중복 병합하지 않았다. 초기 위치 품질 확인이 필요하다.
정상 원본의 새 외형 추적이 가림/외형 변화를 설명하지 못하는 구간도 미해결로 보존했다. 판단 불가를 숨겨
회복된 재현율만 성능 향상으로 홍보하지 않는다. 정상 오탐 원인 보완은 이번에 수행하지 않았다.

  실행했으며 v3 전용 의존성 캐시만 재사용했다. 린트/포맷 및 21개 리포트 artifact 검증도 통과했다.
