# 기존 개발 60개 재채점 결과 — 사건 매칭 v2

동일한 60개 영상의 기존 focused 탐지 결과를 `event-axes-2`로 재채점했다. 영상 분석은 다시 하지 않았다. 기존 6개 성공 평가를 요청 해시·원본 출처·모델 설정으로 검증해 재사용했다.

| 지표 | 영상 수 | 비율 |
|---|---:|---:|
| 기존 v1 자동 대응 | 17/60 | 28.3% |
| v2 의미 대응 | 30/60 | 50.0% |
| v2 의미·시간 포함 대응 | 26/60 | 43.3% |
| 현재 목표 | 51/60 | 85.0% |

현재 1단계 자동 집계는 설명의 핵심 충돌이 없는 의미 대응 + 기존 시간 IoU ≥ 0.1을 유지한다. 의미만 대응하는 영상은 따로 보고하며 성공 수에 가산하지 않는다. 보류 16개, 미대응 18개이며 분모는 모두 60개다. 모두 자동 결과이고 사람 확인 성능으로 표기하지 않는다.

## 실행 상태와 한계

- 평가 상태: {"completed": 60}
- 기존 성공 평가 6개 재사용, 이번 공급자 요청 55회(보완/재시도 포함), 탐지 호출 0회.
- 원본 탐지 실행이 미완료인 영상은 텍스트 평가가 끝나도 자동 성공으로 집계하지 않았다.
- 텍스트 설명의 사건 대응·시간 위치·설명 일관성을 비교했다. 영상 속 사실 정확성은 별도로 검증하지 않았다.
- 전체 60개는 이미 사람이 검토한 개발 자료다. 이번 수치를 독립 검증 성능으로 해석하지 않는다.
