# 의미 매칭 v6 — 핵심 지적, 사건 연결, 제한 재비교

2026-11-06. 서비스는 `review_anomaly_v4`, 기본 평가기 계약은 `event-claims-6`이다.
검출 모델·원본 라벨·후보 목록을 바꾸지 않고 사후 텍스트 매칭을 개선한다.

## 해결한 문제

v5의 `is_anomaly`는 “아무도 와인을 마시지 않는다”처럼 평범한 문장으로 작성된
프롬프트 미준수 라벨을 중립 배경으로 분류해 같은 관측의 C까지 제외할 수 있었다.
또한 출현/복제, 변형/융합 등의 설명 차이를 별개 사건의 증거로 과도하게 사용했다.

v6는 라벨이 실제 오류인지 다시 심사하지 않는다. **원본 라벨이 지적하는 내용과
후보가 기술하는 관측이 같은 사건을 설명하는지**를 비교한다. 라벨 진실성 검증,
영상의 사실 검증, 제작 의도 판정은 이 텍스트 평가기의 역할에 포함되지 않는다.

## 처리 계약

1. **R 독립 분석.** 각 원본 R을 C·다른 R·시간·난이도·이전 점수 없이 분석한다.
   `annotation_type`과 `reference_role=annotated_complaint`는 출처 문맥이며 정답을 추가하지 않는다.
   `role=complaint/context/unresolved`로 핵심 지적·부수 배경·해석 보류를 구분한다.
   동작 부재나 요구사항 실패는 비정상이라는 형용사가 없어도 핵심 지적일 수 있다.
   “분홍색 옷을 입은 여성의 손이 기형”의 옷 색만 일치하는 C는 성공하지 않는다.
2. **사건 요소 추출.** 대상, 구체적 상호작용, 변화·상태·부재를 원문 인용으로 기록한다.
   각 요소는 해당 claim/C의 정확한 부분 문자열이거나 미명시를 뜻하는 빈 문자열이다.
   대상 범위는 `individual/group/part/unknown`이다. R의 구체성
   `specific/broad/unspecified`와 핵심 지적 역할은 독립된 축이다.
3. **전체 R×C 의미 비교.** 독립적으로 동결한 R 해석을 그대로 사용한다.
   `event_link=same_observation/partial_event/process_result/unresolved/distinct_events`로
   같은 관측·부분 사건·과정/결과·불확실·별개 사건의 관계를 기록한다.
   긍정 대응에는 선택한 complaint, 양쪽 정확한 인용, 동일 대상/상호작용,
   구체적 연결 설명, 핵심 모순 부재가 모두 필요하다.
4. **불일치 근거 검토.** `different/related_only` 또는 선택 claim의 핵심 충돌을
   R별로 재검토한다. `separation_basis`는 `none/different_entity/different_interaction/
   distinct_occurrence/contradictory_claim/description_only/insufficient` 중 하나다.
   다른 증상명·설명 상세도·대상 생략만으로 별개 사건을 확정하지 않는다.
   이 규칙은 포괄적 라벨뿐 아니라 구체적 라벨에도 적용한다.
5. **요청된 쌍만 1회 재비교.** 재검토가 정확한 양쪽 인용과 구체적인 같은 사건 연결을
   제시한 경우 `basis=recompare`로 표시한다. 같은 R의 표시된 C들을 모아 별도 비교한다.
   재검토 설명은 가설이며 정답이 아니다. 재비교도 동일한 긍정 대응 계약을 통과해야 한다.
   재검토 단계 자체로 hit를 만들지 않으며 재비교 결과를 다시 검토하는 반복은 없다.
6. **집계.** 의미 대응 하나 이상과 기존 실행 완료 조건을 만족하면 영상별 hit다.
   사건 연결이 불확실하거나 실행/채점이 미완료이면 pending이다. 원본 라벨 밖 후보는
   새로운 정답이나 별도 성공 경로가 되지 않는다. 전체 분모와 85% 목표를 유지한다.

## 인정 범위와 경계

- ‘아무도 마시지 않음’과 ‘잔만 들고 있고 마시지 않음’은 동일 행동 부재의 대응이다.
- 같은 인물의 같은 건배 동작에서 잔이 둘로 복제되는 과정과 추가 잔이 나타난 결과는
  원문상 대상·상호작용이 연결되면 대응할 수 있다. 복제=출현이라는 전역 동의어 규칙은 없다.
- 군집 묘사가 개인을 포함할 수 있으나 누가 어느 물체를 갖고 있는지 불명확하면 보류한다.
- 다른 사람의 잔 소멸을 또 다른 사람의 잔 출현에 자동 연결하지 않는다.
- 같은 사람의 손가락 이상과 신발 색 변화처럼 명시적으로 다른 대상/사건은 불일치다.
- “부자연스러운 움직임”을 궤적 문제로 임의 축소하지 않는다. 형태 변화와 같은 현상인지
  확정되지 않으면 pending이며 표현 차이만으로 no_hit을 확정하지 않는다.
- 일반 측정 제안은 긍정 대응을 얻지 못한다. 영상 사실을 확인한 후보라는 의미도 아니다.

## 시간, 재시도, 이력

시간은 의미 입력에서 제외하며 `시간도 일치/시간 차이 있음/시간 비교 불가`만 보조 표시한다.
사람용 시각은 소수점 세 자리, JSON은 원래 정밀도를 유지한다.

의미 재비교는 표시된 쌍당 논리적으로 최대 1회다. 별도로 기존 전송 정책의
일시적 네트워크 오류 재시도 및 형식 검증 실패 1회 복구는 유지된다.
점수가 기대와 다르다는 이유의 재호출은 하지 않는다. 최종 형식 오류는 pending으로 남긴다.

초기 판정·검토·재비교 판정, 원문 근거, 요청 해시, 모델과 시도 이력을 보존한다.
`reference:* → comparison → review:Rn → recompare:Rn(요청 시)` 순서를 검증하고,
추가 단계·누락 단계·원문 또는 해석 변조·오래된 해시는 거부한다.

v5는 같은 v4 패키지의 `event_matching_v5.py`와 `event_grounding_v5.py`에 보존한다.
이는 다른 서비스 버전에 대한 의존성이 아니다. 기본 실행은 v6이며 v5 캐시는 재사용하지 않는다.
동일 v6 입력·프롬프트·스키마·해시의 완료된 단계만 인증 중단 복구 등에 재사용할 수 있다.

## 검증과 실험

`tests/test_event_matching_v6.py`는 역할, 양쪽 근거, 과정/결과, 보류/불일치,
시간 분리, 미완료 실행, 라벨 없는 후보, 재비교 제한 및 변조 거부를 검증한다.
v5 테스트는 동결된 v5 모듈을 사용해 기존 결과 재현을 확인한다.

실험 입력은 `work/prompt_alignment_new60_20261106/rows.json`의 60개다.
기준 결과는 hit 22 / pending 23 / no_hit 15, 채점 59개 완료·1개 미완료다.
v6 실험은 별도 `work/event_claims6_new60_20261106/`에 원본·코드 해시를 동결한다.
소규모 합성 양성/음성과 기존 문제 사례의 확인 후 전체 60개를 재채점한다.
알려진 사례로 평가기를 개발한 검증이므로 독립 홀드아웃 성능으로 주장하지 않는다.

소규모 실제 Gemini 검증은 완료했다. 합성 사례 7개 모두 사전에 정한 기대 범위에 들어왔다.
동작 부재·같은 대상의 복제 과정/추가 출현은 hit, 다른 인물·다른 신체 부위·반대 진술은
no_hit, 배경 옷 색만 일치하는 경우는 pending이었다. 포괄적 움직임/형태 변화는 hit으로
판단했으며 이를 사람 검증 정답으로 확정하지 않는다.
`sid_079_seedance`는 R4–C3의 동일 행동 부재로 no_hit → hit,
`sid_079_ltx2`는 대상 연결이 불명확해 no_hit → pending이다.
[소규모 검증 기록](event_matching_v6_calibration_20261106.json).

최종 코드의 전체 테스트 355개, Ruff 및 다른 anomaly 서비스 버전 독립성 검사를 통과했다.
재비교의 음성 판정도 자체 양쪽 원문 근거가 없으면 보류하는 경계를 포함한다.

전체 60개 재채점도 완료했다. **hit 26 / pending 23 / no_hit 11**이며,
정상 채점 49개·응답 검증 오류 11개다. 실제 별도 의미 재비교 요청은 0건이었다.
자동 의미 대응 증가와 별개로 원문 인용·축 일관성 응답의 안정성 보완이 필요하다.
