# Spotlight Dataset

### Spotlight: Identifying and Localizing Video Generation Errors Using VLMs

*Aditya Chinchure, Sahithya Ravi, Pushkar Shukla, Vered Shwartz, Leonid Sigal*

**🎉 Accepted to ECCV 2026**

- 🌐 [Project Page](https://spotlight-video.github.io)

## Summary

**Spotlight** is a benchmark for evaluating whether Vision Language Models (VLMs) can precisely
**localize and explain** errors in AI-generated videos. It contains **600 videos** generated by
three state-of-the-art Text-to-Video (T2V) models — **Veo3**, **Seedance**, and **LTX-2** (200 each) —
annotated with **1,604 fine-grained, temporally localized** error annotations across **6 error
categories** and **3 difficulty levels**.

## Abstract

As Text-to-Video (T2V) models progress towards higher visual realism, the artifacts and errors they
produce are highly nuanced, fine-grained, and spatio-temporally localized. Vision Language Models
(VLMs) are actively being adopted as automatic evaluators for video generation, driven by the promise
of their perception and reasoning abilities. Yet, it remains unclear whether they can detect, localize,
and explain fine-grained errors in modern high-fidelity video generations. We introduce Spotlight, a
novel benchmark to rigorously assess whether current VLMs can precisely localize and explain nuanced
video-generation errors. Spotlight comprises 600 videos generated by state-of-the-art T2V models
(Veo3, Seedance, LTX-2), annotated with over 1,600 fine-grained error localizations and explanations
spanning physics, semantics and anatomy. Our experiments reveal that current VLMs lag behind humans
significantly, with humans outperforming our best baselines by nearly 2x on the task. Our analysis
highlights key areas of improvement for utilizing VLMs as automated video evaluators, including the
need for more robust perception and hallucination mitigation.

## Dataset Structure

The dataset has a single **`test`** split with 600 examples. Videos are organized by generator and the
annotations are stored in `test/metadata.jsonl`:

```
test/
├── metadata.jsonl
└── spotlight/
    ├── ltx2/      # 200 videos (sid_001.mp4 … sid_200.mp4)
    ├── seedance/  # 200 videos
    └── veo3/      # 200 videos
```

### Fields

| Field             | Type    | Description                                                                                   |
| ----------------- | ------- | --------------------------------------------------------------------------------------------- |
| `video`           | video   | The generated video (loaded from `file_name`).                                                 |
| `file_name`       | string  | Relative path to the video file, e.g. `spotlight/ltx2/sid_001.mp4`.                            |
| `id`              | string  | Unique example id, `<pid>_<video_from>`, e.g. `sid_001_ltx2`.                                  |
| `pid`             | string  | Prompt id shared across generators, e.g. `sid_001`.                                            |
| `video_from`      | string  | Generator: one of `veo3`, `seedance`, `ltx2`.                                                  |
| `prompt`          | string  | Text prompt used to generate the video.                                                        |
| `annotation`      | string  | JSON-encoded list of error annotations (see below).                                            |
| `orig_dataset`    | string  | Source dataset the prompt was drawn from.                                                      |
| `refvideo_exists` | bool    | Whether a real reference video exists for the prompt (300 `true` / 300 `false`).               |
| `source_data`     | string  | JSON-encoded original prompt metadata (e.g. event list, class).                                |

### Annotation format

`annotation` is a JSON string that decodes to a list of error objects:

```json
[
  {
    "segment": [0, 2],
    "reason": "Dust is floating on the path before the runner even hits those areas",
    "type": "physical_viol",
    "difficulty": "medium"
  }
]
```

- **`segment`**: `[start, end]` timestamps in seconds locating the error in the video.
- **`reason`**: free-text explanation of the error.
- **`type`**: one of the 6 error categories below.
- **`difficulty`**: `easy`, `medium`, or `hard`.

### Error categories (1,604 annotations)

| Type                | Count | Description                                          |
| ------------------- | ----- | --------------------------------------------------- |
| `adherence`         | 455   | Failure to adhere to the prompt (semantics).        |
| `physical_viol`     | 287   | Violations of physical plausibility (physics).      |
| `app_disapp`        | 278   | Objects appearing / disappearing unexpectedly.      |
| `motion`            | 226   | Unnatural or implausible motion (physics).          |
| `anatomy_body_pose` | 183   | Anatomy and body-pose errors.                       |
| `logical`           | 175   | Logical / temporal inconsistencies (semantics).     |

Difficulty distribution: `easy` 793 · `medium` 396 · `hard` 415.

## Usage

```python
from datasets import load_dataset, Video

ds = load_dataset("UBC-ViL/Spotlight-VideoGen-Errors", split="test")
print(ds[0]["prompt"])

# The `file_name` is consumed into the `video` column; disable decoding to read its path
paths = ds.cast_column("video", Video(decode=False))
print(paths[0]["video"]["path"])

import json
annotations = json.loads(ds[0]["annotation"])
for a in annotations:
    print(a["segment"], a["type"], a["difficulty"], "-", a["reason"])
```
