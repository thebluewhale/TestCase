# 벤치마크 집계 v3 — 후보·대응 쌍별 검증 오류 격리

2026-11-12 구현 완료. 집계 계약은 `event-aggregation-3`이다. 의미 판정 계약
`event-claims-6`, 프롬프트, 스키마, 요청 해시, 원본 R/C, 시간 보조 기준은 변경하지 않았다.
[집계 v2](EVENT_AGGREGATION_V2.md)의 세 축 분리와 영상별 hit/no_hit/pending 기준을 유지하고,
기본 비교 응답의 국소 오류까지 격리한다. 사용자에게 검수 결과를 전달하는 검출 경로에는 영향을 주지 않는다.

## 검증 단위

| 오류/상태 | 적용 범위 |
|---|---|
| 원본 입력·요청 해시·단계 순서 불일치, 공통 R 분석 변조 | 재집계 거절 |
| 응답 잘림·차단·JSON 파싱 실패, R/C ID 누락·중복·미지 ID, R×C 연결 구조 오류 | 전체 비교 무효·pending |
| 독립 분석에서 고정한 R 요약/증상 근거를 비교 응답이 변경 | 전체 비교 무효·pending |
| C 요약/필드/범위/원문 인용 검증 오류 | 해당 C와 연결된 모든 쌍 제외 |
| 개별 R–C 인용·축 값·의미 대응 조건 검증 오류 | 해당 쌍만 제외 |
| 불일치 검토가 필요한 쌍인데 기본 비교 실패로 후속 검토가 미실행 | 해당 쌍 제외, 부정 판정 확정 금지 |
| 위 오류와 독립적이며 기존 검증을 통과한 대응 | 의미 대응으로 집계 |

`event_isolation.py`는 기존 엄격한 `validate_judgment`를 참조 전체, 후보 하나,
R–C 하나의 단위로 재사용한다. 원문 인용의 substring 조건 등 의미 기준을 완화하거나
잘못된 근거를 자동 보정하지 않는다. 서로 다른 쌍을 전이적으로 합쳐 대응을 만들지 않는다.

## 원본 응답과 재시도

- 온라인 응답 검증과 최대 1회 형식 재시도는 유지한다. 최종 기본 비교가
  `invalid_response`로 종료된 경우에만 오프라인 집계 단계에서 부분 보존을 시도한다.
- 모든 R 독립 분석과 비교 단계의 입력·요청 해시·순서를 먼저 검증한다.
- **마지막 시도의 정상 종료(`STOP`) 원문 응답 하나**만 사용한다. 이전 시도에서 유리한
  쌍을 가져오거나 여러 시도를 혼합하지 않는다. 마지막 응답이 잘리거나 차단되면 복구하지 않는다.
- `evaluation_status=invalid_response`와 원시 응답은 유지한다. 유효 쌍이 남으면
  `evaluation_validity=partial`, 하나도 없으면 `invalid`이다. 전체 유효로 승격하지 않는다.
- `evaluation_issues`에 오류 범위(`comparison`/`candidate`/`pair`), 해당 ID, 사유를 기록한다.
  국소 검증 실패 쌍은 `pairs`에서 제외하고 이 목록에 남긴다. `unavailable_pair_count`는
  전체 R×C에서 유효 쌍을 뺀 값이다. 제외된 C의 원본 설명은 계속 표시한다.
- 후속 검토·재비교 단계만 실패한 경우에는 기존 v2 방식의 의존 쌍 격리를 유지한다.

하나 이상의 유효한 원본 라벨 대응이 있으면 hit이다. 부분 유효 상태에서 대응이 없으면
pending이며 no_hit으로 확정하지 않는다. 라벨 밖 결함과 일반 측정 제안은 hit으로 세지 않는다.
실패·보류를 포함한 전체 영상 수를 분모로 유지하고 85% 목표도 유지한다.

## 기존 12개 오프라인 재집계

```bash
.venv/bin/python -m review_anomaly_v4.event_reaggregate \
  --source work/parallel_pilot12_20261112 \
  --output work/parallel_pilot12_aggregation3_20261112
```

| 항목 | 집계 v2 | 집계 v3 |
|---|---:|---:|
| hit | 4 | 10 |
| pending | 8 | 2 |
| no_hit | 0 | 0 |
| 채점 전체 유효 / 부분 유효 / 무효 | 5 / 0 / 7 | 5 / 6 / 1 |

`sid_040_ltx2`는 R2–C5를 포함한 6개 의미 대응 쌍을 인정하여 hit이다.
C8의 원문에 없는 근거 인용은 C8 관련 쌍만 제외한다. 유효 쌍은 총 8개,
미사용 쌍은 14개이며 후속 불일치 검토 미실행도 미사용 사유에 포함된다.

남은 pending:

- `sid_079_ltx2`: 최종 비교 응답이 고정된 R 분석을 변경하여 공통 검증 실패. 전체 비교 무효.
- `sid_079_seedance`: 채점은 유효하지만 현재 후보에서 대응이 없고 검출 일부 미완료.

원격 호출은 0회다. 기존 12개는 **Claude 제거 전 병렬 실험**으로, 새 Gemini 단독
실행 결과가 아니다. 10/12=83.3%는 이 표본의 원본 라벨 대응률이며 일반 정확도나
검출 성능 향상으로 해석하지 않는다. 85% 목표에 필요한 11개에는 아직 미달한다.

전체 로컬 테스트 **412개 통과**, Ruff와 버전 독립성 검사 통과.
검증에는 후보 오류 의존 쌍 격리, 단일 쌍 오류 격리, 공통 R/ID 오류 거절,
최종 시도만 사용, 잘림·차단 거절, 미실행 불일치 검토 보류, 단계 해시·순서 검사를 포함한다.
