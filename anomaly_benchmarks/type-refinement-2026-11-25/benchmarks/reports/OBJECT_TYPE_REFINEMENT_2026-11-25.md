## 구현과 근거

`observations/object_reacquisition.py`는 `--seed-dir` 선택 경로에서 병합된 종료 후보의 유형만 보완한다.
새 후보 생성·기존 후보 삭제·시각/영역 변경·coverage 변경을 하지 않는다. OpenCV는 기존 v3 `tracking`
extra를 사용한다. 새 라이브러리·모델·외부 API 호출은 없다. 기본 API 단독 경로는 그대로다.

- 마지막 관측 전 0.1초·마지막 관측·이후 0.1/0.2초의 실제 프레임을 같은 샷에서 확보한다. 서로 다른
  네 프레임·요청 시각 오차 ≤0.02초·인접 간격 ≤0.35초가 필요하다. 영상/샷 경계가 부족하면 설명 유지.
- 마지막 박스 전체의 휘도 외형을 사용한다. 12px 미만·저텍스처 영역을 제외하고 직전 프레임과의 상관
  ≥0.94로 기준 외형의 안정을 확인한다. GT 박스/이벤트·파일명 의미·정상 대조 영상은 입력하지 않는다.
- 기존 폭/높이 9×9 축척에 ±0.05·±0.025 탐색과 정수 크기 ±2px 탐색을 추가한다. 축척은 0.5~2로
  제한하고 같은 크기를 반복 계산하지 않는다. 책 사례에서는 기존 세로 0.6 부근의 불일치를 인접 크기
  탐색으로 줄였다. 단순히 일치 문턱을 낮추지 않았다.
- 두 후속 프레임에서 각각 상관 ≥0.94, 다른 위치의 경쟁 점수와 차 ≥0.05가 필요하다. 재탐색 외형을
  원래 크기로 되돌려 이전 영상에서 찾고, 역방향 상관 ≥0.94·원래 위치 IoU ≥0.8을 확인한다.
  후속 두 박스 IoU ≥0.8 및 동일한 기하 변화 코드도 필요하다. 실제 시간 차의 속도·면적/비율 문턱은 기존 객체 규칙을 사용한다.
- 긴 변 ≤640px, 영상당 최대 4개 종료 후보·협력적 20초 예산이다. 개별 OpenCV 연산을 강제 중단하는
  한도는 아니다. 시간/개수/경계/의존성/매칭 실패 시 원래 설명을 남기고 사유를 기록한다.

책은 변화 전 `[153,147,174,62]`에서 후속 `[101,159,278,39]`의 외형을 찾았다. 후속 두 상관은 약
0.9585, 역방향은 약 0.9478이다. 면적 변화 약 0.5%, 종횡비 변화 약 154%로 비율 급변을 설명한다.
병은 전후 크기가 거의 같고 x 위치가 약 224px 바뀌었다. 두 후속 외형 상관은 약 0.9954다.
수치는 동일 객체일 확률이 아니며, 독립 재식별 모델을 구현한 것이 아니다.

`termination_refinement`에 원래 코드·시각·전후 영역·일치/경쟁/역방향 점수·기하 변화를 보존한다.
원시 이벤트의 `OBJECT_TRACK_END`와 `raw_ids`는 그대로다. finding은 계속 candidate/uncertain이다.
변화 전 박스와 원본 증거에 후속 프레임·재탐색 영역의 원본 크롭을 추가했다. 비교 리포트는 노란 표시가
변화 전 위치라는 점과 설명이 바뀐 이유를 안내한다.
