사람 확인과 제작 라벨을 구분하고, 실패·판단 근거 부족을 성능 분모에서 빼지 않는다.

## 구현과 제한

v3 내부 `observations/object_guard_review.py`를 추가했다. 기존 `--seed-dir` 선택 경로에서만 동작하며
새 모델·라이브러리·외부 호출·형제 서비스 의존성은 없다. 기본 API 단독 경로는 그대로다.

1. 종료 이벤트가 컷 경계·겹침·후속 트랙 가능성으로만 보류됐거나, 내용 유지 보류를 0.18.0의 종료 전
   검사에서 샷/영상 경계 때문에 확인하지 못한 경우에만 재검토한다. 영상 끝·화면 경계·미해결·기존 후보는
   대상에서 제외한다. 기존 API 샷 분할 자체를 수정하지 않는다.
2. 원래 종료 시각 ±0.3초의 실제 프레임을 확인한다. 같은 샷이라는 전제는 재검토하지만 영상 경계는
   넘지 않는다. 최대 4사건·128프레임·협력적 20초 예산이며 사건당 8~24장·간격 ≤0.06초다.
   실패·해상도/샘플 부족·예산 초과는 원래 보류를 유지한다. 개별 연산의 강제 중단 시간은 아니다.
3. 0.18.0의 국소 급변 검사로 안정된 전후 외형과 한 번의 뚜렷한 변화가 있는 시각을 찾는다.
   직전 0.15초 이내 관측 박스에서도 같은 급변 시각을 확인하며, 그 박스가 화면 경계에 있으면 보류한다.
4. 긴 변 최대 640픽셀에서 기존 유형 재탐색의 엄격한 기준을 그대로 적용한다. 기준 외형 안정,
   두 후속 프레임 각각 상관 ≥0.94·다른 위치 경쟁 점수와 차 ≥0.05, 역방향 상관 ≥0.94·원래 영역
   IoU ≥0.8, 후속 두 영역 IoU ≥0.8과 동일한 기하 변화 유형이 필요하다. 단순 소실만으로 컷을 해제하지 않는다.
5. 변화 전 영역과 다시 찾은 두 영역을 제외하고 배경이 화면의 50% 이상 남아야 한다. 이 배경은
   확인 창 모든 프레임에서 첫 프레임 대비 평균 차이 ≤5, 차이 ≥20인 픽셀 비율 ≤1%여야 한다.
   배경이 평탄해서 근거가 없거나 카메라/다른 물체의 변화가 남으면 보류한다. 대상 영역만 비교해 컷을 무시하지 않는다.
6. 관련된 다른 트랙이 급변 전부터 대상과 겹쳤다면 가림 대안을 유지한다. 관련 트랙이 있는 경우에는
   그 후속 관측 영역이 재탐색 외형 위치와 IoU ≥0.6으로 대응해야 한다.

검증 성공 시 원래 이벤트 전체를 `guard_refinement.original`에 저장하고 후보 시각·영역을 보완한다.
원시 이벤트 코드는 `OBJECT_TRACK_END`로 보존하며 병합 후보에 위치/비율 유형을 적용한다.
원래 API 응답·샷 정보와 가드 기록, 배경·외형·역방향·기하 측정이 남는다. 후속 원본 크롭과 쉬운
설명을 리포트에 제공한다. 추론에는 제작 라벨·사람 판정·정상 대조·파일명 의미를 넣지 않는다.

## 검증·재현

새 자체 회귀는 위치/비율 대응, 실제 컷·부분 배경 변화·다른 객체·동일 외형 경쟁, 연속 이동·점진 변화·
복귀·반짝임, 불충분한 배경, 제외해야 할 가드·기존 후보, 영상/프레임/시간 예산·실패 보존을 확인한다.
위치 변화 통합 경로는 샷 경계와 지연된 박스, 원래 보류 기록·유형·후속 크롭·API 단독 경로를 검증한다.
고주파 무늬의 비율 변형은 축소 손실로 상관이 부족할 수 있으며 이 경우 보류를 유지하는 시험도 포함한다.
전체 회귀 **315 passed**, 다른 서비스·LaSOT·cloud SDK 없는 독립 환경의 객체 시험 **100 passed**.
린트·포맷과 39개 리포트/증거 무결성을 확인했다. 실제 브라우저에서 18개 파일 선택·두 영상 재생/동기화,
새 세 후보의 유형/보류 해제 설명·후속 크롭을 확인했다. 모바일 가로 넘침 없음, JavaScript 오류 0건이다.

컵·손 로컬 처리 p50 **1.46초**, p95 **4.34초**; 책·병 p50 **1.01초**, p95 **12.73초**다.
저장된 API 응답으로 처리한 시간이며 공유 환경 부하가 있어 이전 실행과 속도 개선/저하로 단정하지 않는다.

실행은 `work/object-guard-refinement-2026-11-25/`와 `work/object-guard-regression-2026-11-25/`에 보존했다.
재현은 기존 `scripts/refine_object_comparison.py prepare/run/evaluate`와 `compare_object_refinement.py`를
사용하고 부모 실행의 `seeds/`·`human_review.json`을 새 경로로 복사한다. 계획/입력/설정을 동결한 뒤
실행하고 이전 결과를 덮어쓰지 않는다. 영상과 원시 응답은 Git 제외이며 작은 집계·검증 자료만 커밋 대상이다.
