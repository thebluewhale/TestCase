사건 검출과 기대 유형 포함은 각각 **3/8 (37.5%)**, 누락은 **5/8**이다.
사람 확인 정상 8개에서 오탐 **2건 / 2개 영상**이다. 제작 라벨만 있는 대조 2개를 함께 쓰면
정상 라벨 영상은 총 10개이며 오탐은 여전히 2건이다. 두 분모와 라벨 출처를 구분한다.
기존의 “원본 검수 후보 1건 + 정상 대조 오탐 1건”이 사람 확인에 따라 “오탐 2건”으로 바뀐 것이며,
검출기가 새 후보를 만든 것은 아니다.

사람이 정상이라고 확인해도 시스템의 관측 부족 상태는 변경하지 않는다. 정상 확인 8개 중
원본 컵·원본 손·컵 camera의 **3개는 판단 근거 부족**이다. 제작 라벨까지 포함하면 3/10이다.
결함 영상 8개의 시스템 관측 상태는 모두 `verifiable`이나 5개 결함을 놓쳤다. 관측 상태는 실제 결함
검출 성공이나 정상 인증을 뜻하지 않는다. 사람 검수 범위도 객체 소실·급변이며 여섯 검사 전체 인증이 아니다.

## 다음 개발 우선순위

1. **손 소실·위치·크기 누락 3건:** 추적 종료가 실제 변화보다 늦게 기록될 때 변화 전후를 다시 찾는다.
   현재 3.00초 변화에 대해 3.10/3.30초의 이미 변한 프레임끼리 비교하는 문제를 우선 보완한다.
2. **컵 위치·손 비율 누락 2건:** 장면 전환 경계나 트랙 겹침만으로 후보를 보류하지 않도록 배경 변화·
   가림 근거를 확인한다. 정상 컷·가림도 함께 회귀 검증한다.
3. **정상 컵 오탐 2건:** 연속 이동 중의 추적 끊김을 소실과 구별하고, 원본 컵 5.00–5.10초의 후보를
   분석한다. 연속 이동 설명은 사용자 의견으로 보존하며 그것만으로 원본 컵의 알고리즘 원인을 단정하지 않는다.

컵에서 맞힌 3건, 기존 책·물병의 사건·유형 8/8, 정상 대조와 판단 근거 부족 상태를 함께 비교해야 한다.
이번에는 피드백만 반영했으며 위 검출기 보완은 아직 수행하지 않았다. 객체 항목은 **3단계 진행 중**이다.

## 기록과 검증

검수 원문은 영상 SHA·검수한 리포트 SHA·기존 사건 ID와 연결했다. 사용자가 새 시각/영역을 제시하지
않았으므로 동결한 제작 라벨의 시각/영역으로 채점한다. 검수자가 모델 결과를 본 개발 평가이며 독립·블라인드
평가로 취급하지 않는다. 합성 결함도 실제 AI 생성 결함과 구분한다.

반영 전 HTML·분석 메모·안내·검증 기록은 실행 폴더의 `before-human-review-2026-11-25/`에 보존했다.

표시하고 사람 의견이 없는 2개를 구분한다. 저장·내보내기 무결성과 브라우저 확인은
