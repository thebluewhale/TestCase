## 구현과 보존 계약

`observations/object_onset.py`를 v3 내부에 추가했다. 기존 `--seed-dir` 선택 경로에서만 실행하며
새 모델·라이브러리·서비스 간 의존성은 없다. 기본 API 단독 경로는 그대로다.

1. `termination`이 `LOCAL_CONTENT_PRESERVED` 하나의 이유로만 보류됐을 때 확인한다.
   다른 보류 사유·기존 표시 후보는 바꾸지 않는다. 종료 시각 0.4초 전부터 원래 문맥 끝까지 읽는다.
2. 영상/샷 경계를 넘지 않고 실제 PTS의 프레임 간격이 0.06초 이하이며 8~24장이 있어야 한다.
   영상당 최대 4개 사건·96개 프레임·협력적 5초 예산이다. 부족·실패·예산 초과 시 기존 결정을 유지하고
   사유를 기록한다. 개별 디코딩/계산 호출을 강제 중단하는 제한은 아니다.
3. 기존 160×90 휘도 문맥에서 대상 영역은 최소 16×16픽셀이어야 한다. 프레임별 평균 절대 차이 중
   한 단계가 총 변화의 80% 이상·15 이상이고, 그 전후 각각 0.1초 이상 외형이 안정적이어야 한다.
   전후 각 구간의 기준 외형 대비 평균 차이는 5 이하여야 한다. 기준 외형 텍스처와 안정된 배경도 필요하다.
4. 실제 급변이 원래 추적 종료보다 앞에 있어야 한다. 급변 전 0.15초 이내의 API/보조 트랙 관측 박스를
   확보하고 그 시각의 퇴장·겹침·후속 트랙 가드를 다시 확인한다. 그 박스에서도 같은 급변 시각이
   확인될 때만 후보를 만든다. GT·파일명 의미·정상 대조 영상은 사용하지 않는다.
5. 시각·박스를 실제 급변 직전/직후로 보완하고 기존 0.17.0 유형 재탐색으로 연결한다. 소실은 종료 후보로
   유지하고, 손 크기는 후속 외형 대응에 성공해 크기 급변으로 설명한다. finding은 candidate/uncertain이다.

`onset_refinement.original`에 원래 시각·영역·상태·가드·영상 문맥을 보존하고, 전체 확인 시각과 변화량·
전후 안정성·보정 근거를 기록한다. 원시 API 응답은 그대로다. 기존 raw event는 원래 필드를 함께 보존한 채
보정되며, 원시 코드는 `OBJECT_TRACK_END`로 남고 유형 변경은 병합 후보에 기록한다. 증거 크롭과 비교
리포트는 보정된 시각의 실제 원본 프레임을 가리킨다.

신규 자체 회귀는 안정된 외형 사이의 급변, 정상 연속 이동·점진 변화·복귀·짧은 반짝임·컷,
시각 공백/중복·해상도/기간 부족·샷/영상 경계·프레임 예산·디코딩 실패·시간 예산을 확인한다.
소실·위치·크기 통합 시험은 지연된 API 박스, 원래 보류 근거, 새 시각·크롭·유형, API 단독 경로 유지를
확인한다. 별도 채점 회귀는 미검수 원본과 제작 정상 대조를 사람 확인 정상으로 합치지 않는지 확인한다.

책·병 p50 **1.01초**, p95 **11.70초**다. 저장된 응답을 사용한 로컬 시간이며 공유 환경 부하가 있어
이전 실행과 속도 개선/저하로 단정하지 않는다. 실제 브라우저에서 18개 선택·두 영상 재생/동기화,
손 소실/크기의 보정 시각·추가 근거와 정상/누락 표시를 확인했다. 모바일 가로 넘침 없음·JavaScript 오류 0건이다.
