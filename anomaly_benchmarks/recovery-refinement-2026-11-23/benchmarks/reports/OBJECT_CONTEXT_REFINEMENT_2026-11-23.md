## 변경과 근거

### 1. 중간 프레임의 변화 확인

추적 상자는 0.1초 간격이라 그 사이의 정상 움직임도 급변처럼 보일 수 있었다. 원래 문맥 검증을
통과한 위치/크기/비율 변화 후보에 실제 중간 프레임을 추가 비교한다. 긴 변 ≤640px 휘도,
4~24장·인접 간격 ≤0.06초·총 상세 프레임 256장 한도로 동작한다. 시간/해상도/예산 부족 시
기존 후보를 유지하고 추가 검사 불가 사유를 기록한다. 종료 후보에는 적용하지 않는다.

ROI 프레임별 MAE ≥3인 변화가 2회 이상이고 최대 변화 비중 ≤0.65일 때 분산된 변화 대안을 확인한다.
작은 결함이 큰 움직임에 묻히지 않도록 32px 타일/16px 간격에서 MAE ≥15·집중도 ≥0.8인 국소 급변이
하나라도 있으면 후보를 유지한다. 모든 조건을 만족한 구간만 `DISTRIBUTED_LOCAL_CHANGE`로 보류한다.

bottle-12의 원시 구간 9.1–9.2, 9.2–9.3, 9.4–9.5초에서 최대 변화 비중은 각각 약 0.534/0.355/0.406이고
국소 급변 타일이 없었다. 이 3구간이 이전 표시 후보 2건을 만들고 있었다. 책/흔드는 병은 국소 급변이
남아 억제하지 않았다. 이 규칙은 연속 변화에 대한 보조 근거이며, 가림/잔상을 의미적으로 확정하지 않는다.

### 2. 실제 변화 픽셀로 보조 중복 확인

병 위치 결함에서 보조 탐색 박스는 `[204,115,232,40]`으로 넓고 납작했다. 박스 자체를 고치거나 낮은 IoU만으로
병합하지 않았다. 같은 샷·유형·전후 시각의 API 후보와 실제 변한 픽셀을 비교했다. 보조 박스 내 휘도 차 ≥20인
2,302픽셀 중 2,107픽셀(**91.53%**)이 API 박스 안에 있었다. 최소 32픽셀·포함 비율 ≥90% 조건에 따라
API 후보에 보조 근거를 연결했다. 추가 미매칭 표시는 없어졌으나 초기 탐색 박스 품질이 개선된 것은 아니다.

`raw_ids`, `corroborating_tracks`, `corroborating_regions`에 원래 박스와 픽셀 수·포함 비율을 보존한다.
별도 위치 변화·저신호·다른 샷/시각·프레임 부족 시에는 별도 후보를 유지한다. 부분적으로 겹치는 다른
객체를 합칠 위험이 있어 정밀 분할/동일 객체 재식별의 대체로 주장하지 않는다.
