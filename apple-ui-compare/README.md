# Sketch2Image Apple 스타일 비교 스크린샷 (2026-10-07)

같은 장면(스케치 + 영역 2개 설명 + 결과 2장, 영역 1 말풍선 열림)을 헤드리스 Chromium(1280px)으로 찍었습니다.
다섯 단계는 누적 적용이라 N단계 비교의 "변경 전"은 N-1단계 결과입니다. 저장소 코드는 바꾸지 않았습니다.

## raw/ 원본 스크린샷

`s<단계>-<뷰>.png`. 단계 0 = 현재, 1~5 = 해당 단계까지 누적 적용.

- `main`: 전체 페이지 / `scrolled`: 230px 스크롤한 뷰포트 / `tour`: 사용 가이드 1단계
- `pulse-0|550|1100`: 투어 버튼 애니메이션 정지 프레임 / `hover-tray`, `hover-generate`: hover 상태

## stages/ 적용한 CSS

현재 `frontend/style.css` 뒤에 순서대로 덧붙여 찍었습니다. 반영할 때는 이 내용을 style.css에 정리해 넣습니다.

## 참고

- 스크린샷 환경이 Linux라 SF Pro 대신 Pretendard로 렌더링됐습니다 (Windows 사용자도 같은 모습).
- 결과 이미지는 모델 호출 없이 만든 자리표시용 그림입니다.
- 고정 헤더는 투어가 캔버스를 화면 위로 붙이는 동작과 겹쳐, 투어가 열린 동안 고정을 푸는 CSS로 처리했습니다.
